# Cdda-Deep-connections Version 1.1
You ever wanted to screw around with your loyal compatriots? well now you can. This is a very simple mod for followers in CDDA that adds an "enhanced" conversation topic to discuss. this should work on any type of "human" recruit. 
To get this mod working all you have to do is slap the "Deep_connections" mod folder that you download here into your "mods" folder inside your data folder for CDDA then you generate a world and enable this mod in the mod manager.
Alternativly If you want to add this mod to an active game you need to go to your save folder and find your mods.json in the save for your world and add "deep_connections" to the list before the ] .
I updated my mod to work with the new stable update Ito as well, but if you use that version you cannot update the mod once you activate it.
